## 💻 Proyecto destacado

### 🎫 [Ticketera · Sistema de gestión de tickets para soporte TI](https://github.com/JsilvaPro90/ticketera-helpdesk)

Sistema web de Mesa de Servicio (**Help Desk**) desarrollado para centralizar y organizar la gestión de incidencias de soporte TI.

El proyecto permite:

- Registrar y realizar seguimiento de tickets
- Clasificar incidencias por estado y nivel de urgencia
- Administrar empresas, contactos, usuarios y roles
- Visualizar indicadores desde un dashboard
- Gestionar adjuntos y notificaciones por correo
- Importar empresas y contactos de forma masiva desde Excel

**Tecnologías utilizadas:** C#, ASP.NET MVC, .NET Framework, Entity Framework, SQL Server, HTML, CSS, JavaScript y ClosedXML.

➡️ [Ver repositorio](https://github.com/JsilvaPro90/ticketera-helpdesk)
